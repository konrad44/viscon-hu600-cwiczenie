# HU-600 ChickFlow – materiały do ćwiczenia z agentycznego AI

Paczka szkoleniowa do ćwiczenia „Znajdź usterkę, której nie zauważyliśmy”.

**Pobierz (wybierz jedną):**
- [Wersja pełna – HU-600_ChickFlow_cwiczenie.zip](https://github.com/konrad44/viscon-hu600-cwiczenie/releases/latest/download/HU-600_ChickFlow_cwiczenie.zip) (~100 MB, 3 838 plików)
- [Wersja lite – HU-600_ChickFlow_lite_cwiczenie.zip](https://github.com/konrad44/viscon-hu600-cwiczenie/releases/latest/download/HU-600_ChickFlow_lite_cwiczenie.zip) (~41 MB, 1 455 plików, szybsza analiza)

Rozpakuj i otwórz folder w agencie AI (np. Claude Code). Polecenie dostaniesz od prowadzącego.

Wszystkie dane są fikcyjne: osoby, klienci, podwykonawcy, modele podzespołów i pomiary zostały wygenerowane na potrzeby szkolenia.
